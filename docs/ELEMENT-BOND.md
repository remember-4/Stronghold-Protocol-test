# 元素盟约及干员累计更新

## 安装

将更新包解压，把其中的 data、server、shared（如有）、public、tools、test、docs 等目录按原路径合并到项目根目录（package.json 所在目录），同名文件覆盖；不要删除整个项目目录。GitHub 上传时保留目录结构，提交到 Render 使用的分支即可部署。部署完成后所有玩家刷新页面，重新开局。此包不是独立完整游戏，不能单独部署。

## 元素副盟约

场上至少两名不同的元素干员激活；同名普通、精锐不重复计数，人数加成海克斯不能替代第二名真实成员。

- 基础效果：敌人受到我方的元素生命伤害提高 **25%＋0.5%×层数**。0层为1.25倍、40层为1.45倍、100层为1.75倍。元素损伤条积累量不增幅。
- 40层：敌人处于我方触发的任意真实爆发期间，视为所有元素损伤爆发。攻击附加伤害、爆发瞬间的天赋收益及补弹等可以跨类型触发。克莱门莎三技能也能响应其它真实类型的爆发。
- 100层：敌人本场被我方真实爆过条后永久视为所有类型爆发。实际条仍按原规则恢复，恢复后仍可再打满，再次真实爆发正常触发麻痹及天赋收益。
- 虚拟判定不凭空产生其它类型的基础爆发伤害、麻痹、减防或重复事件。基础伤害仍按实际爆发类型与打满条的来源结算，跨类型天赋伤害归触发天赋的干员。
- 恢复速度和持续时间修改始终只操作对应真实类型。例如酒神只加速真实神经条恢复，不能加速凋亡条。
- 不修改敌人施加给我方的元素损伤。同场多人激活时使用最高层数，不把多个盟约增伤重复相乘。爆发历史每场重置。

## 来源与兼容

克莱门莎数据和技能来自 sganggs/Stronghold-Protocol 提交 bc50cac01ff447eff3ab6c35f69d934bbc23b48f；仅移入该干员，未整体覆盖原作者其它更新。素材由原作者资产配置指定的公开资源镜像下载。原作者技能实现对部分上线初期细节标注了 ASSUMED，例如三技能第一轮轰击在0.5秒后落下，此包保留这些实现。

更新生成器为 `tools/custom/element-roster.mjs`，克莱门莎的输入快照为相邻的 `clemnt-unit.json`。在本更新版本中执行 `node tools/custom/element-roster.mjs` 可重建本轮新增固定卡及特质。它依赖本包已经具备的元素盟约与成员配置，不是针对任意未来版本的通用迁移器。

本累计包保留当前 test 仓库已有海克斯与自定义逻辑；不把旧 Rem 仓库内容重新迁入。

## 侵蚀专项复核

引擎原已有侵蚀机制，本包没有另造一套损伤类型。真实敌方侵蚀爆发造成5000基础元素伤害、永久防御力-120、8秒冷却。冷却期锁定全部损伤条，结束后条重置；永久减防保留，多次真实爆发可重复减防。元素盟约只增幅元素生命伤害，不增幅侵蚀打条量；40层虚拟侵蚀不会凭空减防，100层永久判定不阻止真实条恢复或再次爆发。敌人对我方的侵蚀仍按原800物理伤害、永久减防100、10秒冷却处理。

原版领袖免疫侵蚀打条，本包保留；因此对领袖不能打出真实侵蚀爆发。界面已有侵蚀水滴图标和对应损伤条。本次新增9项侵蚀测试，包括普通/精锐克莱门莎真实三技能攻击的附加打条、界面数据、伤害/减防/恢复/重复爆发与领袖免疫。
