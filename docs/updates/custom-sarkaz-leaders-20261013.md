# 遗志满层触发与三名新领袖

基于 remember-4/Stronghold-Protocol-test 最新提交 5face81643823b806fd9b8f42613f66a068d257c。保留此前的萨卡兹改动、干员特质、逐回合海克斯设置和默认皮肤功能。

## 安装

将更新包内文件按原路径覆盖至仓库根目录，提交到部署分支，等待 Render 部署完成后刷新网页。无需修改 Docker/Render 配置。新领袖出现在原有的领袖选择界面，沿用标准初始生命28。

## 遗志满层

普通规则仍为每名干员至多30层遗志。满30层后再次获得遗志，仍会刷新六人萨卡兹的攻防翻倍1秒，时间刷新但不累加。未达到六人额外效果时不会产生翻倍。

超过上限的量不会实际加到遗志，不计入黑冠联动，也不额外产生黑冠的技力或无敌效果。这次仅改变满层后翻倍的触发。每层法抗仍固定为1点，不翻倍。

## 赫德雷：佣兵契约

进入休整期，首次商店最左侧可购买干员标记为“雇佣兵”，商店卡片会显示标签。每回合只标记一名；手动刷新后新卡不再被标记。冻结商品在新回合的首次商店按同一规则重新处理。

购买后，标记绑定获得的干员。合成精锐保留雇佣兵身份；详情中显示身份标签。

自己的场上有至少一个雇佣兵时，可上场人数+1，多个雇佣兵不叠加。即使原上场人数已满，也允许把首个雇佣兵放上场。最后一个雇佣兵撤回或售出后，上限恢复，多出的干员按原规则撤回整备区。

## 维什戴尔：巴别塔的信号弹

购买本局从未获得过的干员：号召+1。按实际干员种类记录，普通/精锐以及不同同角色卡形态视为同一种；之前通过奖励、领袖赠送等渠道获得过也算已获得，卖掉不清除记录。购买失败不计数。

每回合前三次手动刷新各号召+1，免费刷新也计入。新回合自动更新商店不计入这三次。

每累计6点号召，消耗6点，获得一次免费刷新，并保存一次“下次商店刷新干员价格-1”的折扣。最低价格为0，不影响装备价格。

折扣应用到下一次商店更新，包括下一回合自动更新；冻结并保留的旧商品不算新刷出的商品。刷新动作本身凑满6点时，折扣作用于再下一次刷新，不能追溯作用于当前已刷出的卡。折扣按次数保存，每次更新只消耗一次，不会在同一次刷新叠成价格-2。号召进度和待用折扣在策略效果提示中显示。

## 特雷西娅：文明的存续

自己的萨卡兹干员遗志取消30层上限，攻击、防御与固定法抗均按实际遗志计算；复活仍保留原遗志，倒地时仍向其他存活萨卡兹平均传承。

自己的萨卡兹干员被击倒时，使萨卡兹盟约层数+1。通过装备转职为萨卡兹的干员也可触发；盟约尚未激活时也可加层；撤退、移动等非击倒事件不触发。其他玩家不会因你的领袖选择而解除遗志上限。

遗志仍仅在本场战斗内积累，不跨战斗继承。

多人同时佩戴黑冠与休眠子裔时，无上限遗志可能形成循环。加入来源链保护：同一条黑冠衍生链不返回已参与过该链的干员，正常的新遗志、不同来源和非循环联动仍生效，避免无限循环卡住战斗。原有30层上限队伍的黑冠规则不改变。
