# 每回合海克斯设置、凛视显示与默认皮肤更新

适用仓库 remember-4/Stronghold-Protocol-test，基准提交 a0e3100d363ca36c141c4bf5adbfc9565b111b87。

## 安装

将更新包中的文件按路径覆盖到仓库根目录，提交至部署分支，等待 Render 完成部署。无需修改 Docker 或 Render 设置。部署完成后刷新网页；若出现旧版本提示，按提示刷新。

## 使用

开房间界面选择“海克斯与敌方强化 → 调整”。房主也可以在房间中、开始游戏前修改。所有成员均可看到回合列表。房主修改后，其他真人玩家需要重新准备。

每个回合两列独立勾选：
- 我方海克斯：当轮是否让玩家（含 AI）获得海克斯选择。
- 敌方强化：当轮是否进行全队敌方强化投票。敌方总开关关闭时，所有敌方投票均停止，我方设置不受影响。

“默认安排”保持原先规则：我方第1–13回合；敌方第2、4、6、8、10、12、13回合。另有“每回合双方”“仅我方”“全部关闭”快捷设置。

支持第1–15回合，第14、15回合默认关闭，只有实际进入对应回合才生效。开启后在该回合休整前选择；我方品质概率沿用第13回合，敌方使用首领强化池。第13回合仍使用首领强化池。首次敌方强化禁止彩色的限制跟随最早勾选的敌方回合。

取消某回合勾选只跳过当轮的新选择，不清除已获得的海克斯或敌方强化。品质权重沿用现有规则。创建设置保存在当前浏览器中。

## 凛视

凛视技能说明原有未替换占位符，现按各数据形态的黑板数值补齐。普通版二技能攻速+22、附带20%攻击力的凋亡损伤；精锐版攻速+35、附带25%。一技能可充能2次。只修复说明显示，不改变战斗数值。数据来源核对： https://prts.wiki/w/Valarqvin 。原始生成用的 threye-unit.json 同步修复，重新生成数据时不会恢复旧占位符。

## 皮肤

新部署版本首次打开页面后，清除旧版皮肤偏好，默认使用皮肤列表最右边的一款。没有皮肤时使用原始外观。同一版本内的手动选择（含原始外观）会保留，刷新不会再次重置。沿用本机显示，不影响战斗属性。

使用现有 /healthz.build 判断版本。检测服务暂时不可用时保留偏好，待下一次成功启动检测。静态托管不提供此接口时，仍可默认使用最右皮肤，但无法检测部署版本。
