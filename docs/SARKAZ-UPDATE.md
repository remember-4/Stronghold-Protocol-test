## 萨卡兹盟约

3名不同萨卡兹干员激活，6名达到第二档。同名普通/精锐只计一名，沿用主盟约人数规则。

3人：每名萨卡兹干员每在场存活5秒或亲自击杀一名敌人，获得1层本场遗志。每层攻击、防御增加（2+0.015×萨卡兹层数）%。例如100盟约层时每层遗志+3.5%攻防。每名干员最多持有30层遗志，超出部分直接舍弃，不触发获得事件，也不参与之后的传承。遗志不是永久盟约层数，战斗结束清空。

被真正击倒时，遗志全部转给同一玩家其他在场存活的萨卡兹干员，平均分配，保留小数；例如1层分给两人各0.5层。无人接收则消失。该干员复活后从0层开始，5秒存活计时重新开始。主动撤退、强制退出、伤害被复活机制拦截且未发生击倒的情况不触发分配。

6人额外：每次萨卡兹干员实际部署、被击倒时，使同一玩家所有存活萨卡兹干员各获得1层遗志。首次部署与重新部署都算。每次获得事件使遗志效果翻倍1秒，再次获得将结束时间刷新为当前时间+1秒，时间不累加；倍率保持2倍，不变为4倍、8倍。继承一批遗志算一次获得事件，触发翻倍刷新。击倒时先给存活者1层，再分配阵亡者遗志。

这些作用范围和小数分配是对表格未细分处的实现解释；联防不把另一玩家的遗志自动转给本玩家。维什戴尔的首次技能判定也按自己的阵容，复活后不会重置“首次”。

## 可露希尔资金

借款资格来自作战区或整备区持有的精锐可露希尔，不要求萨卡兹或远见激活；临时整备区不提供资格。商店购买、刷新、调度中心升级及经过正常支付入口的效果可使用额度。UI显示资金下限与待偿还余额。

每份可露希尔特质独立按实际本回合花费叠层，并各有上限。休整结束时资金为负，所有这类特质都不叠层，再将欠款转成两倍待偿还金额，当前资金归零。期末已还到0或正数，则正常叠层，不产生罚款。下一回合收入到账后偿还，不计为“本回合花费”；收入不够则扣完可用收入并保留余额。出售可露希尔不能消除已产生的欠款。

## 数据、素材与生成

凛视数据来自 Kengxxiao/ArknightsGameData 国服 character_table、skill_table、range_table、battle_equip_table、uniequip_table；快照在 tools/custom/threye-unit.json。头像、立绘和技能图标来自 yuanyan3060/ArknightsGameResource，前后战斗模型来自 fexli/ArknightsResource。已解析骨骼并检查图集区域。其余4名新增固定卡沿用当前仓库已有数据和素材。

执行 node tools/custom/sarkaz-roster.mjs 重建本轮卡池与特质。该生成器依赖本包已有元素版本，不是任意未来版本的通用迁移器。旧 tools/custom/element-roster.mjs 若重跑，会恢复旧妮芙/菲莱等配置；因此修改或重建时，先运行元素生成器，再运行萨卡兹生成器。

## 黑冠与休眠子裔

休眠子裔保持原4阶、回血效果、普通/进阶数值及合成规则；额外作为萨卡兹对应装备。与变形同构体同时佩戴时获得萨卡兹成员身份，参与人数统计和遗志机制；单独休眠子裔不转职。

黑冠为6阶特殊装备，普通购买4费，两件普通合成进阶，规则与天师古鼎相同。普通防御力+45%，进阶+70%，基础防御加成对所有携带者生效。萨卡兹成员实际获得遗志时，每次事件回复4技力并刷新0.5秒无敌，技力遵守技能自身的技力接收规则；6人遗志翻倍仅影响遗志攻防属性，不能加倍装备的技力或无敌时间。

同时佩戴黑冠和任意品质休眠子裔：同一玩家其他在场萨卡兹干员每累计实际获得4层遗志，携带者获得1层。保留累计的小数与余数，统计继承所得；不统计自身获得或被30层上限舍弃的部分。累计8层产生两次各1层获得事件；触发得到的遗志也可以被其他符合条件的黑冠统计。处理使用队列并受30层上限约束，不产生无限递归。携带者被真正击倒后，组合累计余数清空。

继承一批遗志算一次获得事件；即使继承的是0.5层，黑冠仍触发一次+4技力和0.5秒无敌。满30层后没有实际获得，不反复触发装备。

黑冠图标使用用户指定的“文明的存续”：https://prts.wiki/w/“文明的存续”，资源文件 rogue_6_relic_legacy_11.png 来自 fexli/ArknightsResource 的 rogueitem 目录。本包只使用其图像，装备机制按用户设计，不使用原藏品的真实伤害易伤效果。

重建本轮数据时，在运行 sarkaz-roster.mjs 后再运行 node tools/custom/sarkaz-equipment.mjs。累计包包含前一轮全部文件变更，直接覆盖当前项目即可，无需先上传前一轮萨卡兹包。
